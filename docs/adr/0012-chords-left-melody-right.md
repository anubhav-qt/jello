# 0012: Chords on the left, melody on the right

- Status: Accepted
- Date: 2026-10-20

The default laptop layout splits the hands, like an accordion. The left hand
plays chords: each letter key from A to G plays the major chord with its
name, so a chord chart is played by typing it. The right hand plays the
melody, one fixed note per key, so the same note in two octaves is two keys
that can sound together. Replaces the accordion grid on both hands. The
layout itself is in [design.md](../design.md#computer-keyboard).
