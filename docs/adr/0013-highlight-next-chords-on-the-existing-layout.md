# 0013: Highlight next chords on the existing layout

- Status: Accepted; guidance groups superseded by 0017
- Date: 2026-10-20

Keep the current chords-left, melody-right layout (ADR 0012) and the familiar
typing keys. When composing in guided mode, highlight the available next
chords and explain natural choices, less fitting choices, and unusual
choices that can still work, so the player can try them by ear. When playing
a composed song, highlight its actual upcoming chords. Use the existing
keyboard and Stage style; hints never remap keys or block other chords.
Build this alongside composing and song playback, without redesigning the
key map now. Details are in [design.md](../design.md#chord-guidance).
