# 0027: Computer keyboards only

- Status: Accepted
- Date: 2026-10-21

Jello is played on computer keyboards only: the laptop's and the desktop's.
No MIDI keyboard will be bought, so v1's step 3 (MIDI keyboard input) is
dropped, and the other steps keep their numbers. Typing keys have no
velocity, so every note plays at one loudness; expression comes from the
sound itself, layer volumes, the mixer and automation instead. Typing keys
also drop some combinations held together, so layouts and the learning
mode (v2) only ask for keys these keyboards can read at once. The learning
mode trains both hands on the computer keyboard. MIDI files as song content
stay. Answers the open question of laptop keys or a MIDI keyboard in
[design.md](../design.md#open-questions).
