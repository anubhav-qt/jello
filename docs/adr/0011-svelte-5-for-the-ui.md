# 0011: Svelte 5 for the UI

- Status: Accepted
- Date: 2026-10-20

The webview UI moves from plain TypeScript to Svelte 5 (MIT). It reads closest
to plain HTML and TypeScript, compiles to small fast JS, and Tauri has an
official template. Heavy visuals stay on canvas. Picked over React, SolidJS
and staying plain.
