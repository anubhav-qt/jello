# 0019: Instruments built from scratch, no guitar

- Status: Accepted
- Date: 2026-10-20

Every instrument and effect in Jello is our own code, written from scratch:
no instrument libraries, no amp models and no hosted plugins as the way to
production-grade sound. The aim is drums, piano and whatever else the
user's five reference artists use, playable in Play, Compose and Produce.
Guitars are left out for now: guitarless music is the trademark. This
replaces the Guitars section planned for after v1.
